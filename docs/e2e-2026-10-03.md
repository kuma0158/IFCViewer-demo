# E2E テスト記録（2026-10-03 / 本番ビルド配信の状態）

対象: フロントエンド本番ビルド（`vite preview` :5173）+ バックエンド（FastAPI :8001）。Cloudflare Tunnel 経由の公開ホスト名 `ifc.shinobuabe.com` も含む。

## 方針

- **利用者と同じ入口から確かめる。** API も `:5173` の `/api` 転送を通して呼ぶ（バックエンド直ではない）。
- **2 層に分ける。**
  - API・配信: 繰り返し実行できるスクリプト `scripts/e2e_api.py`（標準ライブラリのみ。追加の依存なし）
  - 画面: ブラウザ（Chrome）で実際に操作して確認（下の手順）
- **他の利用者に影響を与えない。** バックエンドの再起動はしない（起動時に `uploads/` を消すため）。テストでアップロードしたファイルは自分の分だけ削除する。公開ホスト名では 100MB 超のアップロードを行わない。
- Playwright などのブラウザ自動化ライブラリは、依存が大きいため今回は導入しない（7 節）。

## 4. 実施中に分かったこと

- **Cloudflare は Python 標準の User-Agent（`Python-urllib`）を 403 で弾く。** curl や独自の名前なら通る。スクリプトは `ifc-pilot-e2e/1.0` を名乗るようにした。今後スクリプトから公開ホスト名を叩くときは同じ点に注意。
- **Chrome 拡張が複数のブラウザ（このPC と Mac）に接続されている。** Mac 側で `localhost` を開くと、このPCではないため表示できない。画面のテストは「このPC」のブラウザを選んで行う。
- **自動操作ではスクリプト実行直後の最初のクリックが効かないことがある。** 実際の利用では起きない（手でのクリックは毎回効く）。テストでは先に空の場所を一度クリックしてから操作した。

## 追記: 100MB 超のアップロード対応（分割アップロード）後の E2E

背景: 公開ホスト名経由で大きな IFC を開くと「通信エラー (413)」になった。原因は **Cloudflare の 1 リクエスト 100MB 制限**（`Server: cloudflare` の HTML で 413 が返り、バックエンドには届いていない）。
対応: 画面からのアップロードを 16MB ずつの分割アップロードに変え、解析は裏で行って進み具合を問い合わせる形にした（Cloudflare の応答待ち 100 秒制限も回避）。上限は 500MB。

| # | 内容 | ローカル | 公開 |
|---|---|---|---|
| E1 | 分割アップロード（小さいファイル）→ 解析 → モデル取得 | ✅ | ✅ |
| E2 | 分割アップロードで壊れたファイルは status=error と原因 | ✅ | ✅ |
| E3 | 500MB 超は開始時点で 413 | ✅ | ✅ |
| E4 | 拡張子が .ifc でなければ 400 | ✅ | ✅ |
| E5 | チャンクの大きさが違えば 400 | ✅ | ✅ |
| E6 | 全チャンクが揃う前の完了通知は 409 | ✅ | ✅ |
| E7 | 存在しないアップロードは 404 | ✅ | ✅ |
| D1 | 500MB 超（501MB）の一括アップロードは 413（上限変更に合わせて 101MB → 501MB） | ✅ | 省略 |
| F1 | 120MB の IFC（合成データ）を分割アップロード → 解析 → ダウンロード | ✅（約 2 秒） | ✅（送信＋解析 16 秒、ダウンロード 8 秒） |
| | **合計（スクリプト）** | **28/28** | **25/25 ＋ F1 個別実行** |

画面（Chrome・このPC）: 120MB のファイルを開くと、ステータスが「送信中… 79%（96.0 / 120.0 MB）」→「サーバーで解析中…」→「部材 8 件 / 3Dメッシュ 8 件」と変わり、約 4 秒で 3D 表示。壁のクリックで属性表示、コンソールエラーなし。

合成データ（`scripts/e2e_api.py` の `synthetic_ifc()`）はサンプル IFC に参照されないプロパティ値を詰めて大きくしたもので、形状は元のまま。**形状が多い実データの大きな IFC では、ブラウザ側（web-ifc）の 3D 変換に時間とメモリがかかる点は未確認**。

バックエンド単体テストは 15 件（分割アップロードの組み立て・検証・期限切れ・解析までの一連、合計サイズでのモデル破棄を追加）。
